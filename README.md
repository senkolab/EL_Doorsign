# SenkoLab door sign

The QuDit Lab door display v1.2.0 is in [lab-status-display](lab-status-display/README.md). It supports the Raspberry Pi touchscreen, HDMI relay, wavemeter status, and automatic Paladin shutter status.

[Download QuDit Lab Remote for Windows x64](https://github.com/senkolab/EL_Doorsign/releases/latest/download/QuDit-Lab-Remote-Windows-x64.zip)

The original hardware design and AVR firmware are in [EL_Doorsign_PCB](EL_Doorsign_PCB) and [src](src).
